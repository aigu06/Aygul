# Book Tracker

Автор: Абсалямова Айгуль

## Описание
Book Tracker — GUI‑приложение для учета прочитанных книг. Оно позволяет:
- Добавлять книги по названию, автору, жанру и количеству страниц.
- Просматривать книги в таблице.
- Фильтровать по жанру и по количеству страниц (например, больше 200).
- Сохранять и загружать данные в формат JSON.

Данные хранятся в файле `books.json`.

## Запуск
1. Установите Python 3.
2. Сохраните файлы `app.py`, `books.json` и `README.md` в одну папку, например `book_tracker/`.
3. В терминале перейдите в эту папку и запустите:
   ```bash
   python app.py
   ```
4. При первом запуске файл `books.json` может отсутствовать — это нормально, программа создаст пустой список.

## Использование
1. Введите название книги, автора, жанр и количество страниц.
2. Нажмите «Добавить книгу» — книга появится в таблице.
3. Для фильтрации:
   - В поле «Жанр» введите часть жанра (поиск без учёта регистра).
   - В поле «Страниц больше» укажите число (например `200`).
   - Нажмите «Применить фильтр».
4. Для сохранения:
   - Нажмите «Сохранить JSON» и выберите место сохранения файла.
5. Для загрузки:
   - Нажмите «Загрузить JSON» — программа загрузит книги из выбранного файла.

## Примеры тестов
- Пустое поле: при нажатии «Добавить книгу» появится ошибка «Все поля должны быть заполнены».
- Страницы = `abc` или `12ab`: при нажатии «Добавить книгу» появится ошибка «Количество страниц должно быть числом».
- Жанр = `Фантастика`: в таблице останутся только книги, где жанр содержит `фантастика` (с учётом регистра).
- Страницы больше `200`: таблица покажет только книги с большим числом страниц.

## Git и GitHub

### 1. Настройка локального репозитория
В папке проекта выполните в терминале:
```bash
git init -b main
git add .
git commit -m "Initial commit"
```

### 2. Выложить проект на GitHub
1. Создайте новый репозиторий на GitHub (без README и .gitignore).
2. Скопируйте URL репозитория (например, `https://github.com/USERNAME/book_tracker.git`).
3. На локальной машине добавьте удалённый репозиторий и отправьте:
   ```bash
   git remote add origin https://github.com/USERNAME/book_tracker.git
   git push -u origin main
   ```
После этого ваш проект будет выложен на GitHub и доступен по ссылке.
